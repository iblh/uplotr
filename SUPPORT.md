# Support

uplotr is a community-supported Public Beta and does not include a commercial SLA.

- Use [GitHub Discussions](https://github.com/iblh/uplotr/discussions) for setup questions, integration ideas, and usage help.
- Use [Issues](https://github.com/iblh/uplotr/issues) for reproducible bugs and scoped feature requests.
- Use private vulnerability reporting for security concerns; see [SECURITY.md](SECURITY.md).

When asking for help, include the uplotr version, deployment method, expected behavior, and sanitized logs. Never post API keys, passwords, session cookies, database URLs, exact private coordinates, or raw production payloads.
